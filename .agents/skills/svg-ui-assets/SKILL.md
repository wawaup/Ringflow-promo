# SVG UI Asset Skill

Create clean, scalable, Apple-like vector UI assets.

Rules:

- Prefer SVG/React components over raster images.
- Use consistent stroke width.
- Use rounded caps and joins.
- Use subtle gradients and shadows.
- Support light and dark themes.
- Keep icons simple and legible at small sizes.
- Avoid brand logos unless supplied by the user.
