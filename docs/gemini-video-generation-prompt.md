# Ringflow macOS Promo Video — Gemini Video Generation Prompt

**用途**：直接复制整个内容作为 Gemini（Veo / 高级视频生成模型）的提示词。包含完整视频目标、风格规范、编排原则和逐场景详细描述。

## 视频总体目标与规格

**视频名称**：Ringflow macOS 宣传片  
**时长**：约 48-50 秒（紧凑、专业、无拖沓）  
**分辨率与帧率**：1920×1080，60fps  
**风格定位**：极致苹果风 / macOS 原生感。优雅、干净、玻璃质感、克制动效。白蓝浅色主题 + 深蓝灰暗色主题（用于系统/脚本/监视类场景）。  
**核心卖点**：Ringflow 是 macOS 动作轮盘工具。通过中键长按 + 右划在光标附近召唤真实轮盘，用高亮扇区精确驱动操作，实现“常用的，应该更近一点”。

**必须严格遵守的原则**（每帧都要体现）：
- **轮盘是绝对主角**：所有功能演示场景必须**先出现轮盘**，配置为当前场景对应的真实扇区，然后**对应扇区先高亮**，再出现结果 UI。结果出现时轮盘高亮必须领先或同步。
- **真实 macOS App 内容**：所有轮盘标签必须使用真实可添加的内容（复制、粘贴、撤销、保存、全选、新脚本、监视器、新便签 + 提示词文件夹里的总结提炼、润色改写等）。严禁编造。
- **真实文字**：所有屏幕文字（标题、窗口标题、内容、反馈）必须来自真实 copy。中文自然、专业。
- **macOS 原生 UI**：所有窗口必须有标准红黄绿交通灯、玻璃材质、系统字体、真实阴影。严禁 placeholder 方块+文字。
- **动效原则**：克制、优雅。文字先出现建立主题 → 视觉元素进入 → 动作执行（轮盘高亮 → 结果）。动作后只留极短连接停顿（0.2-0.5s）。零长时间静态死气。零间隙连贯切换。
- **构图**：左文右图或上文下图为主。文字可读性第一。轮盘大小根据场景角色（hero/standard/mini）保持一致。
- **色彩**：浅场景 #f8fbff → #edf7ff → #ffffff 渐变 + 丝带；深场景深蓝灰。强调色为蓝色。
- **参考图像一致性**：严格参考上传的参考图保持轮盘外观、窗口玻璃质感、光标、整体调性。

## 详细镜头描述（可直接用于生成）

**总时长控制**：前 8 秒建立痛点与理念转折，中间功能演示紧凑有力（每段 2.8-4.2s），结尾品牌收尾干净。

### 0-8 秒：痛点 + 理念 + 产品亮相（核心转折）

**0-4.8s：正在做的事，应该保持连贯。**
- 浅色优雅背景。
- 左侧大标题逐行出现：“正在做的事， 应该保持连贯。”
- 右侧出现真实 macOS 工作场景：一个代码/文档窗口（当前任务上下文），下方 AI 输入区，一个黄色便签窗口（会议纪要，真实内容）。
- 便签内容被选中 → Control + C 键帽出现 → 内容粘贴到输入区。
- 提示词列表窗口出现，“润色改写”被选中 → Control + C/V。
- 强调操作打断专注的烦躁感。真实文字、真实窗口玻璃质感、光标闪烁。

**4.8-7.6s：找来找去。来回切换。一遍又一遍。**
- 快速展示菜单栏 → 二级菜单 → 窗口切换的抽象但优雅视觉（卡片或真实窗口叠层）。
- 文字左对齐或居中，强调重复切换的成本。

**7.6-13.6s：理念转折 + Ringflow 亮相（最重要 hero 镜头）**
- 文字：“常用的， 应该更近一点。”
- 画面中央出现真实 macOS 文档窗口（项目计划.md，真实内容，有选中文字）。
- 光标在窗口内。
- **Ringflow 轮盘在光标旁边召唤出现**（hero 大小，清晰显示 8 个真实扇区：复制、粘贴、撤销、保存、全选、新脚本、监视器、新便签）。
- 文字叠加：“Ringflow 出现在光标旁边。”
- 轮盘使用浅色玻璃，中心 “Ringflow” 或 “默认”。
- 强调“出现在光标旁边”的核心价值。

**13.6-17.8s：核心交互教学**
- 文字：“按住中键，向右一划。”
- 大教学光标（中键高亮）+ 向右滑动轨迹。
- 轮盘出现（可带外环文件夹），目标扇区高亮。
- 释放后显示结果反馈。
- 轮盘必须清晰展示真实扇区和交互反馈。

### 17.8s 之后：功能演示（每个都必须 wheel → highlight → result）

**17.8-21s：常用文字，一划输入。**
- 场景：真实编辑器窗口 + 提示词侧边栏。
- **轮盘先出现**（真实“润色改写”扇区高亮）。
- 高亮后，输入区插入提示词 + “Ringflow 已输入：润色改写 · 剪贴板已恢复” 反馈出现。
- 真实文字，干净结果状态。

**21-24.2s：常用应用、文件、文件夹，一划打开。**
- 编辑器上下文。
- 轮盘出现，高亮“快捷打开”相关扇区。
- 结果：Terminal / Finder / 项目文件夹卡片出现或小窗口弹出，显示已打开。
- “Ringflow” 归因。

**24.2-27.4s：灵感，不必打断。**
- 正在编辑的会议记录文档。
- 轮盘出现，高亮“新便签”扇区。
- 结果：便签窗口在旁边浮出，真实内容“下次同步前确认三件事”，显示 Ringflow 已创建。

**27.4-30.7s：复杂流程，一次划动。**
- 深色场景。
- 轮盘出现，依次高亮多个扇区（复制 → 切换 → 粘贴 → 保存）。
- 高亮滑动过程清晰。
- 步骤列表依次完成，带 Ringflow 轮盘运行中状态。

**30.7-33.7s：脚本，也可以一划运行。**
- Terminal 窗口。
- 轮盘高亮“新脚本”。
- 命令执行 + 成功输出 “Done in 2.4s”。
- 真实等宽字体，深色玻璃。

**后续场景（33.7s-45.8s）按相同模式：**
- 快捷指令、监视器（深色，状态面板 + 轮盘高亮 “监视器”）、不同 App 不同轮盘（三栏配置卡片，轮盘切换）、预设库（下载导入列表 + 轮盘）。
- 每个场景轮盘必须先出现，对应扇区高亮后再出结果 UI。

**45.8-48.6s：品牌收尾**
- 居中文字：
  “让 Mac 操作，
  更接近直觉。
  Ringflow”
- App Logo 优雅出现 + 呼吸动画。
- 简洁下载信息（macOS 14+）。
- 整体干净、品牌感强。
